# Article 5

Le droit réel principal Sauf disposition particulière de la loi, les droits réels principaux sont:
1° la propriété ;
2° l'usufruit ;
3° les droits d'usage et d'habitation ;
4° l'emphytéose ;
5° le droit de superficie ;
6° les servitudes et les services fonciers ;
7°Al HoubsouAlwaqf, 8°Almouqharasa,
9° El oumra
10° Chefaa

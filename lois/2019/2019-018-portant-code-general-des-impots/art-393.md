# Article 393

1) Les salaires bruts annuels réels des Conservateurs de la propriété foncière font l’objet d’un prélèvement au profit du budget de l’État dont le taux est fixé selon le tarif suivant :
 de 0 à 12.000 OUGUIYA : 0 %  de 12.001 à 20.000 OUGUIYA : 55 %  de 20.001 à 30.000 OUGUIYA : 60 %  de 30.001 à 40.000 OUGUIYA : 65 %  de 40.001 à 80.000 OUGUIYA : 75 %  de 80.001 à 140.000 OUGUIYA : 80 %  de 140.001 à 200.000 OUGUIYA : 85 %  de 200.001 à 500.000 OUGUIYA : 90 %  au-dessus de 500.000 OUGUIYA : 92 %
2) Le prélèvement est effectué chaque trimestre par le Conservateur lui-même.

# Article 258

La production et l’importation des produits suivants sont soumises à une taxe de consommation :
 1° produits pétroliers ;
 2° alcools ;
 3° tabacs ;
 4° eaux minérales ;
 5° sucre ;
 6° produits laitiers ;
 7° pâtes alimentaires ;
 8° fer à béton ;
 9° ciment ;
 10° emballages en plastiques ;
 11° cartes de recharge téléphonique.

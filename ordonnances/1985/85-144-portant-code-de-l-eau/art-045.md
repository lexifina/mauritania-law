# Article 45

Les agréments délivrés dans le cadre du Code des investissemnets doivent mentionner obligatoirement la nécessité d"obtention d"un décret de concession. Ces agréments sont suspendus, en matière d"hydraulique, jusqu"à l"entrée en vigueur du décret de concession.

# Article 128

Les impôts, droits de douanes et recettes assimilées sont liquidés et recouvrés dans les conditions prévues par le code général des impôts, le code des douanes, les lois, ordonnances et règlements.
Le règlement par remise d’obligations cautionnées de droits de douane, d’impôts, de droits indirects n’est admis que dans les conditions fixées par le code des douanes et par le code général des impôts.

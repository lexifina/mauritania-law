# Article 34

Le règlement de dialogue définit les modalités de passation du dialogue compétitif. Il précise le nombre de phases que devra suivre le dialogue compétitif. Il précise l’éventuelle prime dont pourraient bénéficier les candidats soumissionnaires dont l’offre finale valide est rejetée.
Il est établi dans les mêmes conditions prévues par l’article 21 précédent.

# Article 5

Les membres de l’Inspection Générale d’Etat bénéficient d’une gratification annuelle dont le montant est détaillé comme suit :
Pour l’Inspecteur Général d’Etat : 150.000 MRU (cent cinquante mille ouguiyas) ; Pour les inspecteurs généraux d’Etat adjoints : 100.000 MRU (cent mille ouguiyas) ; Pour les inspecteurs vérificateurs : 80.000 MRU (quatre vingt mille ouguiyas).

# Article 177
Lorsque la radiation non consentie par le créancier est demandée par voie d'action principale, cette action est portée devant le tribunal compétent du lieu où l'inscription a été prise. Si l'action a pour objet la radiation d'inscription prise dans des ressorts différents sur un fonds et ses succursales, elle sera portée devant le tribunal compétent dans le ressort duquel se trouve l'établissement principal.

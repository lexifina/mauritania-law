# Article 944
Sauf les chèques au porteur, tout chèque émis dans un pays et payable dans un autre pays peut être tiré en plusieurs exemplaires. Lorsqu'un chèque est établi en plusieurs exemplaires, ces exemplaires doivent être numérotés dans le texte même du titre, faute de quoi chacun d'eux est considéré comme un chèque distinct.

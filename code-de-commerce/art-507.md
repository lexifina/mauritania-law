# Article 507
La procuration donnée pour se faire représenter à une assemblée par un actionnaire et signé par celui-ci, indique ses prénom, nom, et domicile. Le mandataire désigné n'a pas faculté de se substituer une autre personne. Le mandat est donné pour une seule assemblée. Il peut cependant être donné pour deux assemblées, l'une ordinaire, l'autre extraordinaire, tenues le même jour ou dans un délai de 15 jours. Le mandat donné pour une assemblée vaut pour les assemblées successives convoquées avec le même ordre du jour.

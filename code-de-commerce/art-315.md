# Article 315
(Loi n°2015-32) Les parts sociales ne peuvent être représentées par des titres négociables. Elles ne peuvent être cédées qu'avec le consentement de tous les associés. A défaut d'unanimité, la cession ne peut avoir lieu mais les statuts peuvent aménager une procédure de rachat pour permettre le retrait de l'associé cédant.

# Article 65
L'amende est prononcée par le tribunal compétent dans le ressort duquel se trouve l'intéressé sur réquisition du magistrat chargé de la surveillance du registre du commerce l'intéressé entendu ou dûment convoqué. Le tribunal compétent ordonne que l'inscription omise soit faite dans un délai de deux mois. Si dans ce délai, elle n'a pas été opérée, une nouvelle amende peut être prononcée. Dans ce dernier cas, s'il s'agit de l'ouverture d'une succursale ou d'une agence d'un établissement situé en dehors de la Mauritanie, le tribunal compétent peut ordonner la fermeture de cette succursale ou agence jusqu'au jour où la formalité omise aura été remplie.
